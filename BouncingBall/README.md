## 打砖块游戏

在打砖块游戏中，我们需要控制挡板，让小球击打砖块，获得胜利。

注意：在本项目中，请不要使用任何DSL语言，而是使用最原始的方式，类似于`example.ts`中的格式进行书写。

### 游戏规则

- 场景：矩形画布，左上原点；墙体为不可穿透边界。
- 组件：一个挡板、一个小球、单层砖块（耐久=1）。
- 小球速度：标量速度固定，不做难度递增与上下限夹制。
- 碰撞：
  - 墙与砖块：镜面反射（切向不变、法向取反）。
  - 挡板：镜面反射的同时加上一定比率乘以挡板速度的水平分量，夹制到恒定速度。
- 砖块消除：被命中即消除，不支持贯穿与多层砖块。
- 得分：每消除 1 个砖块加固定分值（例如 +100），不设连击与关卡结算加成。
- 生命：初始 3 条；小球越过底部边界判定失球，生命 -1；生命为 0 游戏结束。
- 胜利：当前场景所有砖块被清除即胜利；不做多关卡。
- 重置：失球后重新发球。

### 代码规范

按照`example.ts`的风格作为规范。具体的：

- 代码分为3个区域：节点定义、控制流、数据流
- 节点定义区域将所有节点定义下来
- 控制流写代码的控制逻辑
- 数据流写代码的运算逻辑
- 最后使用`encode_gia_file`函数导出
- 所有代码均需遵循`utils`文件夹下的相关规范，严格按照注释的节点、类等定义，不得自行定义节点
- 如果同一节点需多次使用，请按功能分别命名它们，以作区分

### 实现细节

- 在《原神：千星奇域》中，物品的移动是通过运动器实现的，但并不能通过运动器得到速度。因此，在让小球运动时，你需要在小球内部存储一个三维向量存储它的运动（虽然竖直分量y永远为0），以便碰撞触发时计算新的速度
- 很多问题可以通过发送信号的方式解决，如当小球碰上边界，碰撞事件发生在边界，而速度改变发生在小球，因此可以发送信号给小球，让小球处理
- 由于工具链的一些问题，信号名当前无法编辑，故请在代码写完后编写`REPORT.md`文档，告诉我应该加哪些信号
